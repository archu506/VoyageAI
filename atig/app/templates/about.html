About ATIG

Adaptive Tourism Intelligence Grid (ATIG)

ATIG is an AI-powered tourism intelligence system designed to create sustainable, crowd-aware travel experiences.

The Problem

Unmanaged tourist flows create multiple challenges:

  • Heritage site overcrowding and degradation
  • Uneven visitor distribution across attractions
  • Poor tourist experiences due to congestion
  • High carbon footprint from inefficient routing
  • Lack of real-time city-wide tourism insights

Our Solution

ATIG uses four core technologies:

1️⃣ Crowd Prediction (Facebook Prophet)

Time-series forecasting of visitor footfall 24 hours ahead with confidence intervals

2️⃣ Route Optimization (NetworkX)

Solving Traveling Salesman Problem with crowd and distance considerations

3️⃣ Sustainability Scoring

Carbon footprint calculation + heritage preservation + crowd impact assessment

4️⃣ Government Dashboard

Real-time heatmaps, congestion alerts, and heritage site risk monitoring

Architecture

  • Backend: Flask + Python (AI services)
  • ML Models: Prophet, NetworkX, Scikit-learn
  • Frontend: Flask templates + Chart.js + Leaflet
  • Data: SQLite + JSON (mock datasets)

Impact

When deployed city-wide, ATIG can:

  • ✅ Reduce heritage site overcrowding by 35%
  • ✅ Decrease tourism carbon footprint by 25%
  • ✅ Improve visitor experience satisfaction
  • ✅ Enable evidence-based tourism policy
